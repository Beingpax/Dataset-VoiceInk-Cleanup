One cleanup contract

Every target uses the same polished style. Filler words, repetitions, stutters, false starts, and verbal editing artifacts are removed. Punctuation, capitalization, formatting, and unambiguous structured values are restored. The target does not summarize, embellish, or reorder the speaker’s ideas.

Preserve meaning

The semantic content and order remain stable. Cleanup is not an invitation to improve the author’s argument.

Finish the writing

Targets include natural punctuation, capitalization, paragraphs, lists, quotations, greetings, and sign-offs.

Keep examples traceable

Each record carries a principal category, complete error tags, formatting features, language, source, and policy version.

Recommended composition

The dataset should teach isolated behaviors clearly, then demonstrate the combinations found in real ASR output. A small no-change slice discourages unnecessary editing.

The 50-example demonstration

The planned 2,000-pair batch targets 1,000 single-principal records, 900 natural multi-error records, and 100 no-change records. The old generator collection has been removed; the replacement batch has not been generated. See the README for current authoring rules.

Planned coverage

The examples cover both cleanup errors and dictated document structure. Formatting is treated as part of the target, not as a separate output style.

  • Punctuation and capitalization
  • Fillers and repetitions
  • Stutters and false starts
  • Explicit self-corrections
  • ASR substitutions
  • Numbers and dates
  • Times and measurements
  • Currency and percentages
  • Email addresses and URLs
  • Filenames and identifiers
  • Dictated punctuation
  • Paragraph breaks
  • Ordered and unordered lists
  • Headings and quotations
  • Greetings and sign-offs
  • Literal command words
  • Correct no-change inputs
