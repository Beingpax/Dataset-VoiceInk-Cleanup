Method, without the black box

        
The first dataset contains the original twenty seeded-random validation rows plus thirty longer additions. The second contains all fifty supplied curated input/reference pairs, preserved with their category metadata. Local models ran sequentially on the same machine. Hosted-provider memory and throughput are not exposed.

      

      

        

          
S1-mini configuration

          
Its README is followed exactly: required system prompt, required control line, greedy decoding, and enable_thinking=False. Styling is semi-formal, structure is prose, and context switches to email only for email-shaped references.

        

        

          
Local measurements

          
Response latency is wall-clock generation time for each local response. The table reports arithmetic mean and median for the selected dataset view. Tokens per second is output tokens divided by the same measured interval. Peak memory is process peak RSS or the llama.cpp server process-tree peak.

        

        

          
Read the scores carefully

          
References encode one preferred rendering. A colon instead of a comma can be sensible and still lose exact match. Dataset-level results remain separate because the validation sample and curated pairs have different construction and difficulty.
