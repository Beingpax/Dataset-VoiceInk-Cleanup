# Viewing the benchmark

From the project root, start a static server:

```sh
python3 -m http.server 8765
```

Then open `http://127.0.0.1:8765/comparison/site/` from the repository root.

The site has no package manager, build step, external fonts, tracking, or network dependencies. Its benchmark data source is `comparison/site/data/benchmark.json`, generated by `comparison/benchmark/score_results.py`. The JSONL viewer is implemented by `jsonl-viewer.js` and can load repository datasets or local files.
