# Product

## Register

product

## Users

A single private dataset author reviewing instruction-fine-tuning examples for transcript cleanup. The user needs to inspect raw ASR input, polished output, record metadata, and category coverage without reading dense JSONL lines.

## Product Purpose

Turn a local JSONL dataset into a legible review workspace. Success means the user can load a file, find records quickly, understand each transformation, spot inconsistent examples, and assess dataset balance without uploading private data anywhere.

## Brand Personality

Quiet, editorial, precise. The interface should feel calm enough for close reading and rigorous enough for dataset work.

## Anti-references

Avoid dashboard-heavy analytics, decorative gradients, excessive cards, gratuitous animation, neon AI styling, and developer tools that expose raw structure before readable content.

## Design Principles

- Put the transcript pair first; metadata supports the reading task.
- Make filtering immediate, legible, and reversible.
- Preserve privacy by processing files entirely in the browser.
- Use editorial hierarchy to make long-form text comfortable to compare.
- Reveal raw JSON on demand instead of making it the primary view.

## Accessibility & Inclusion

Target WCAG AA contrast, complete keyboard operation, visible focus, reduced-motion support, color-independent status labels, and layouts that remain usable from narrow mobile widths through wide desktop screens.
